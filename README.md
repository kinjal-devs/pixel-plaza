# Pixel Plaza 🎮

A cute, detailed pixel-art shopping town game built with HTML, CSS and JavaScript.

## Run locally
Open `index.html` in a modern browser. No build tools or dependencies are required.

## Current playable foundation
- Isometric town scene with a central fountain and four connected streets.
- All 20 planned shops represented; selected starter shops are open and the rest are marked as locked.
- Player movement with WASD / arrow keys and a touch joystick.
- Tap a shop or walk close and use the interact button to inspect it.
- Responsive layout for desktop and mobile.

## Project files
- `index.html` — game interface and overlays
- `styles.css` — cosy pastel / brown / beige UI styling
- `game.js` — isometric scene, shop data, movement and interactions

## Roadmap
This is the first playable town foundation. Next milestones: player customization and pet companion, shop interiors and shopkeeper tasks, inventory and virtual coins, customer behaviour, upgrades, saving, sound, and progression/unlocks.

All game coins are virtual in-game currency.
