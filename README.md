# Pixel Plaza 🎮

A cosy pastel shopping-town game made with HTML, CSS and vanilla JavaScript.

## Run the game
Open [index.html](index.html) in a modern browser. No build tools or package installation are needed.

## Current playable features
- Isometric shopping town, central fountain and four connected districts.
- The complete 20-shop catalogue, with starter shops open and the others unlockable using virtual coins.
- Keyboard movement (WASD / arrow keys), touch joystick and shop interaction.
- Shop screens with customer requests, different customer moods, product choices and coin rewards.
- Shop-level upgrades and town progression.
- Character wardrobe with hairstyles, hair colours, outfits, accessories and shoes.
- Choose a cat, dog, bunny or duck companion.
- Inventory and supply restocking.
- Daily task/reward panel and town progress.
- Settings for music/SFX levels and language selection.
- Automatic local save plus manual save/load controls.
- Responsive layout for desktop and mobile.

## Files
- `index.html` — game interface
- `styles.css` — town and interface styling
- `game.js` — isometric town, movement and shop data
- `game-systems.js` — wardrobe, pets, shopkeeping, inventory, progression, tasks and saving

## Important
This is an early playable build. The visual town and systems are in place, but several production-level features still need deeper implementation and testing: fully unique illustrated interiors and preparation minigames for every shop, animated character/pet sprites, customer pathfinding and queues, persistent daily calendar/reward cycles, per-district music tracks, detailed furniture/decor placement, and complete device/browser testing.

All coins are virtual in-game currency. There are no real-money purchases.
